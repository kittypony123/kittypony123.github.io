Coordinator App

For volunteer coordinators to manage registered attendees for each session.

  • View master list of all people
  • Add/remove people from session registrations
  • Filter by volunteer or participant type
  • Save registration changes

Attendance Tracker App

For lead volunteers to mark daily attendance for pre-registered individuals.

  • Select site, session, and date
  • View pre-registered volunteers and participants
  • Mark attendance with simple toggles
  • Save attendance records

Setup Instructions

Before using these applications, you need to set up the backend:

  1. Create a Google Sheet with four sheets: Sites, Master People List, Registered Attendees, and Attendance Log
  2. Set up the Google Apps Script backend in your Google Sheet
  3. Deploy the Apps Script as a web app
  4. Configure the Apps Script URL in both frontend applications

For detailed instructions, please refer to the Deployment Guide.
