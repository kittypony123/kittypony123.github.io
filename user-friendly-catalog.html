Let's Get Your Data Ready

Before we start, make sure you have exported these CSV files from your BI tool:

  • Tables - Basic table information (names, descriptions, row counts)
  • Columns - Column details (names, data types, descriptions)
  • Relationships - How tables connect to each other
  • Measures - Calculated fields and KPIs
💡 Tip: These files are typically named like "view_tables.csv", "view_columns.csv", etc.

Name Your Semantic Model

Give your data model a meaningful name. This helps organize multiple models if you have them.

✨ Example names: "Sales Dashboard Model", "HR Analytics", "Financial Reports"
