ℹ️ Import Guidelines

  • CSV files should be UTF-8 encoded
  • Dates should be in YYYY-MM-DD format
  • Times should be in HH:MM format (24-hour)
  • Patient IDs must match existing patients for interactions/outcomes
  • Empty cells will be treated as blank values
  • Duplicate entries will be skipped
